Map fonts bundled with StudyMap

These are free fonts with the same letter widths as the fonts journals ask for, so a figure keeps its
layout when an editor opens it with the original font. They are embedded in exported PDFs.

  Arimo    looks like Arial / Helvetica   Apache License 2.0     LICENSE-Arimo-Apache-2.0.txt
  Tinos    looks like Times New Roman     SIL Open Font License  OFL-Tinos.txt
  Carlito  looks like Calibri             SIL Open Font License  OFL-Carlito.txt
  Caladea  looks like Cambria             SIL Open Font License  OFL-Caladea.txt
  Cousine  looks like Courier New         SIL Open Font License  OFL-Cousine.txt

Source: Google Fonts (https://github.com/google/fonts), downloaded 2026-10-18.
Arial, Helvetica, Times New Roman, Calibri, Cambria and Courier New are trademarks of their owners;
the fonts above are separate designs that only share their letter widths.
